## 2. Steps
Order: schemas / SQL / interfaces → tests → implementation → docs.

- [x] 1. **Housekeeping** — move `_setup/` files into place, `chmod +x` hooks, verify, delete `_setup/`.
- [x] 2. **Tooling** — `pyproject.toml` (`requires-python = ">=3.12,<3.13"`, deps from spec §7);
      `uv sync`. Ruff: line-length 100, rules `E,F,I,UP,B,SIM,ASYNC`. Mypy strict on `app`, `jobs`,
      `config` with `pydantic.mypy` plugin. Pytest: `asyncio_mode = "auto"`,
      `addopts = "-m 'not llm and not network'"`, markers registered.
- [x] 3. **Docker** — `docker-compose.yml` + init SQL; update `.env.example`; `make up`; confirm
      `healthy`, both DBs exist, `SELECT extversion FROM pg_available_extensions WHERE name='vector'` ≥ 0.8.
- [x] 4. **Settings** — `config/settings.py` per spec §4 (`SettingsConfigDict(env_file=".env", extra="ignore")`).
- [x] 5. **Models** — `app/db/base.py` naming convention
      (`ix_%(table_name)s_%(column_0_N_name)s`, `uq_…`, `ck_%(table_name)s_%(constraint_name)s`, `fk_…`, `pk_…`);
      `app/db/models.py` with `Mapped[...]` types, `Vector(384)` from `pgvector.sqlalchemy`,
      `ARRAY(Text)`, `JSONB`, `server_default`s, `CheckConstraint`s, expression GIN index via
      `Index(..., text("to_tsvector('simple', title)"), postgresql_using="gin")`, HNSW via
      `postgresql_using="hnsw", postgresql_ops={"embedding": "vector_cosine_ops"}`,
      `job_runs` index with `started_at.desc()`. Embedding dim from a module constant tied to
      `EMBEDDING_DIM` (384) — changing it needs a migration anyway.
- [x] 6. **Alembic** — `alembic.ini`, async `env.py` (URL from `get_settings()` unless `-x db_url` given),
      `target_metadata = Base.metadata`. Autogenerate `0001_initial_schema` against an empty DB, then
      review by hand: add `CREATE EXTENSION IF NOT EXISTS vector` first, verify HNSW / GIN / DESC
      indexes, CHECKs, server defaults, `ON DELETE CASCADE`; write `downgrade()` in reverse FK order.
      Fixed revision id `0001`.
- [x] 7. **Tests (write before step 8–10 code)** — see §3. Run: migration/constraint tests pass
      against step 5–6; health/settings tests fail until step 8–10.
- [x] 8. **LLMClient** — `ping()`: `GET {base_url}/api/tags` with `httpx.AsyncClient(timeout=...)`;
      any `httpx.HTTPError` / non-2xx → `LLMUnavailable`. Injectable `http` client for tests.
- [x] 9. **Health service** — `check_health()`: DB check = `SELECT 1` under `asyncio.wait_for(timeout)`;
      Ollama check = `llm.ping()` under the same timeout; both run concurrently (`asyncio.gather`);
      jobs = `SELECT DISTINCT ON (job) ... ORDER BY job, started_at DESC` (skipped if DB down).
      Aggregate: db down → `down`; ollama down → `degraded`; else `ok`. Error strings are exception
      class name + short message, with the DSN never included.
- [x] 10. **Router + app** — `app/api/v1/health.py` uses `Depends(get_session)`, `Depends(get_llm_client)`,
      `Depends(get_settings)`; returns `JSONResponse(status_code=503)` when `down`. `app/main.py`
      `create_app()` + module-level `app`; engine disposed in lifespan. DB-down path: session
      dependency must not raise before the handler runs (connect lazily inside `check_health`).
- [x] 11. **Wire-up** — Makefile targets; `CLAUDE.md` commands; `make migrate` on the main DB.
- [x] 12. **Docs** — HLD §8 (SQL block → spec §4 SQL, "10 tables", design notes on CHECK vs ENUM,
      cascade policy, chunk natural key), §6 (resumability via `embedded_at` / `map_prompt_version`),
      §13 tree. Set plan status `done`.

## 3. Test plan
- **Unit:**
  - `tests/config/test_settings.py` — loads from env vars (monkeypatch, `_env_file=None`); missing
    `DATABASE_URL` raises `ValidationError`; Flipkart secrets are `SecretStr` (not in `repr`).
  - `tests/app/services/test_health.py` — status aggregation with `FakeLLMClient` (ok / unavailable /
    timeout → `degraded` within ~timeout); latest-run-per-job with 3 `job_runs` rows across 2 jobs.
  - `LLMClient.ping()` with `httpx.MockTransport` (200 → ok, 500 → `LLMUnavailable`, `ConnectError` → `LLMUnavailable`).
- **Integration (real Postgres, `phonematch_test` only):**
  - `test_migration.py` — session-scoped fixture runs `alembic upgrade head` on the test DB via
    `-x db_url`. Tests: test DB reachable; 10 tables exist; `vector` extension installed; all named
    indexes exist (from `pg_indexes`), HNSW uses `vector_cosine_ops`; `format_type` of `embedding`
    is `vector(384)`; `downgrade base` leaves 0 app tables (only `alembic_version`), then
    `upgrade head` again; `alembic check` → no new upgrade operations.
  - `test_constraints.py` — per-test transaction + rollback (savepoint per statement); each bad
    insert raises `IntegrityError`: bad `review_videos.status`, bad `tier`, bad `price_band`,
    digest `camera = 11`, `feedback = 0`, duplicate chunk natural key, duplicate `phones.slug`,
    `review_videos` with NULL `phone_id`. Plus one positive case: deleting a phone cascades to its
    prices, digest and chunks.
  - `tests/app/api/test_health.py` — `httpx.AsyncClient(transport=ASGITransport(app))`, dependency
    overrides: real test-DB session + `FakeLLMClient` → 200 `ok`; fake unavailable → 200 `degraded`;
    session bound to an unreachable URL (`localhost:1`) → 503 `down`, `jobs == []`.
- **Real-LLM (`@pytest.mark.llm`, skipped by default):** one test pinging the real local Ollama.

If Postgres isn't running, the integration tests fail with a clear message from `conftest.py`
("run `make up`"). They are not skipped silently.

## 5. Risks and rollback
- **Autogenerate misreads pgvector / expression indexes** → hand-review (step 6); `test_models_match_migration`
  catches drift. If `alembic check` false-positives on the expression GIN index, exclude that single
  index in `env.py`'s `include_object` and note it as a deviation.
- **Port 5432 already in use** (Homebrew Postgres) → set `POSTGRES_PORT` in `.env` and both URLs.
- **Init script not run on an old volume** → `make db-shell` + `CREATE DATABASE phonematch_test`.
- **The hooks misbehave once installed** (e.g. the format hook fails before `uv sync`) → it already
  skips when ruff is missing; worst case remove the hook entry from `.claude/settings.json`.
- **Rollback:** `alembic downgrade base`; `docker compose down` (the volume is kept — `down -v` is
  denied in settings on purpose).
